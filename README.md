# MinecraftAFK 26.2

Minecraft Java 26.2 + Fabric istemci modu.

- F6: AFK hareketini açar
- F7: AFK hareketini kapatır
- Açıkken karakter yaklaşık 2 saniyede bir sola/sağa hareket eder.
- Multiplayer'da Alt+Tab sonrasında istemci tick almaya devam ettiği sürece hareket sürer.

## GitHub Actions ile derleme

Depodaki dosyaları GitHub'a yükleyin. Ardından **Eylemler** sekmesine girip **Modu Derle** iş akışını çalıştırın. İşlem bitince **Artifacts** bölümündeki `MinecraftAFK-26.2` paketini indirin.

Oyunda Fabric Loader 26.2 ve Fabric API gereklidir.
